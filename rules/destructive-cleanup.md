Never bundle deletions (`rm`, `rm -rf`, `git clean`) into a compound Bash command with other steps — issue the deletion as its own standalone command so the permission prompt shows exactly what gets removed, and so a denial doesn't discard the rest of the work. Put scratch/temp files in the session scratchpad directory (auto-allowed, auto-cleaned), never in the repo tree or `/tmp`, so cleanup deletions are rarely needed at all.
